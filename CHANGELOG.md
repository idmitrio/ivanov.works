# История изменений

## [1.1.3] - 2026-08-16

### Изменено

- На первом экране вместо «персональной инженерной ИИ-студии» теперь прямо указаны разработка и внедрение ИИ-решений.
- Заголовки и описания для поисковых систем, превью ссылок и структурированной разметки приведены к основному описанию сайта: сначала проверка на одном процессе и данных компании, затем разработка и внедрение полноценного решения.

## [1.1.2] - 2026-08-16

### Исправлено

- Исправлена разметка favicon для Яндекса: сайт теперь указывает один SVG-файл размером 120 × 120 и явно сообщает его формат.

## [1.1.1] - 2026-08-15

### Добавлено

- Добавлены карта сайта, правила для поисковых роботов, структурированные данные и подтверждение сайта для Яндекс Вебмастера.

### Изменено

- Поисковые системы теперь получают в исходном HTML тексты всех сценариев решений и ответы на вопросы, даже если эти блоки свёрнуты на странице.
- Для публичных и служебных страниц настроены отдельные канонические адреса и правила индексации. Шаблон будущего кейса исключён из поисковой выдачи.

## [1.1.0] - 2026-08-13

### Добавлено

- На `pypi.ivanov.works` добавлено закрытое хранилище для собственных Python-пакетов. Клиентские проекты забирают из него готовые сборки без обращения к Git.
- В README добавлены настройки `uv` для публикации и установки пакетов.

### Безопасность

- Доступ к хранилищу защищён Basic Auth. Контейнер не открывает отдельный порт наружу, не перенаправляет запросы в публичный PyPI и хранит данные в отдельном Docker-томе.

## [1.0.4] - 2026-08-06

### Добавлено

- В верхнее меню добавлена ссылка «Контакты» с переходом к футеру.
- В FAQ добавлены ответы о выборе между автоматизацией, ИИ-помощником и агентом, экономическом эффекте и изменениях в рабочем процессе.

### Изменено

- В форме «Обсудить процесс» теперь можно оставить адрес электронной почты или номер телефона. Политика обработки персональных данных обновлена с учетом этого изменения.
- Обновлена скачиваемая презентация ИИ-студии.

## [1.0.3] - 2026-07-31

### Добавлено

- На первом экране добавлена ссылка для скачивания презентации ИИ-студии.

## [1.0.2] - 2026-07-30

### Исправлено

- Удалена техническая панель «Процесс / Данные / Проверка / Решение» под первым экраном.

## [1.0.1] - 2026-07-30

### Изменено

- Обновлены главный заголовок и подзаголовок сайта, а польза типовых сценариев автоматизации сформулирована понятнее для потенциальных клиентов.
- Увеличен логотип в основной шапке сайта.
- Обновлены заголовки страниц, описания для поисковых систем и превью ссылок для социальных сетей и мессенджеров.
- Добавлены более наглядные примеры заполнения формы «Обсудить процесс».
- Страница политики обработки персональных данных закрыта от индексации и упрощена визуально.

### Исправлено

- Заголовки и значки FAQ больше не окрашиваются системным синим цветом на iPhone.

## [1.0.0] - 2026-07-30

### Добавлено

- Адаптивный сайт ИИ-студии Дмитрия Иванова для экранов 1440 и 390 px с главной страницей, мобильным меню, FAQ и прямыми контактами.
- Раздел решений, показывающий пользу автоматизации документов, заявок, поддержки, поиска по базе знаний и управленческого контроля.
- Форма «Обсудить процесс» с валидацией, подтверждением обработки персональных данных, состояниями отправки и защитой от повторной отправки.
- Политика обработки персональных данных с описанием данных формы, файлов cookie и Яндекс.Метрики.
- Яндекс.Метрика с Вебвизором, картой кликов и целями открытия формы и успешной отправки заявки.
- Адаптивный шаблон будущего кейса и комплект фирменных логотипов, favicon и Open Graph-изображение.
- Production-развёртывание в Docker с Next.js, Caddy, автоматическим HTTPS, healthcheck и хранением сертификатов в постоянных томах.

### Безопасность

- Секреты формы используются только в серверном обработчике и исключены из Git и Docker-контекста.
- Приложение запускается в контейнере от непривилегированного пользователя и доступно извне только через Caddy.
